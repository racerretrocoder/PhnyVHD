# PhnyVHD
Version 1.02

PhnyVHD is a Custom Hard Drive utility that can Read and Write to internal and external storage mediums
Supports (Depending on your computer configuration / RAID Controller) Internal HDD's External HDD's USB Drives, Floppy disks, Flash cards
There are no storage limits. Supports all partition tables, file systems, and more

Compatible with Windows 7, Python 3.8.8
